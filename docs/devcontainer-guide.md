# Devcontainer Guide

## Überblick

Für die gemeinsame Entwicklung mit Home Assistant und Alpha ESS Wallbox steht im Workspace-Ordner ein gemeinsamer Devcontainer als Basis bereit.

## Verwendung

1. Öffne den Workspace-Ordner in VS Code.
2. Wähle „Reopen in Container“.
3. VS Code baut den Container auf und installiert die gemeinsamen Python-Tools.

## Repo-spezifische Varianten

- Für das Home Assistant-Repository kann der Container direkt aus dem jeweiligen Repository geöffnet werden.
- Für das Alpha ESS Wallbox-Repository wird dieselbe Basis verwendet, mit einem leicht angepassten Namen.

## Vorteile

- Gleiche Tooling-Basis für beide Projekte
- Schneller Einstieg ohne doppelte Setup-Schritte
- Einheitliche VS Code-Erweiterungen
